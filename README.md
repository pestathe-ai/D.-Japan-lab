# D. Japan Lab

App Android per usare **ZenMarket** (zenmarket.jp) comodamente dallo smartphone.
App non ufficiale: apre il sito vero, non è collegata a ZenMarket / ZenGroup Inc.

## Funzioni (v0.1)
- Tutto il sito ZenMarket dentro l'app (ricerca, aste Yahoo/JDirectItems, Mercari, Rakuten, Amazon, carrello, ordini, pacchi, account). L'accesso resta salvato.
- Barra in basso: **Home · Negozi · Cerca · Carrello · Account**.
- **Cerca** accetta parole o un link incollato (Mercari, Yahoo…); se hai un link copiato te lo propone.
- **Calcolatore ¥ → €** (icona ¥ in alto): prende i prezzi dalla pagina aperta, aggiunge commissione ZenMarket, spedizioni, IVA 22% e dazi oltre 150 €. Cambio aggiornato dalla BCE.
- **Preferiti** (☆ in alto), copia link, apri nel browser, tasto Indietro del telefono che torna alla pagina precedente.
- Impostazioni: lingua del sito, commissioni, IVA/dazi, cancella accesso e dati del sito.

## Limiti
- Le pagine sono quelle del sito: se ZenMarket cambia qualcosa, l'app lo mostra così com'è.
- Caricare file dal telefono (es. foto per l'assistenza) non è ancora supportato nell'app: usa "Apri nel browser".
- Le cifre del calcolatore sono stime; commissioni e dazi reali dipendono da ZenMarket, corriere e dogana.

## Installazione
Scarica `app-arm64-v8a-release.apk` dall'ultima Release e installalo.
